# Quran Key 2.1.1

Patch release focused on bundle size and settings compatibility.

## Changes

- Compress the bundled Quran corpus and root search index in `main.js`; both datasets remain available offline and are expanded when the plugin starts.
- Reduce the production bundle from 12.4 MB to about 1.39 MB, below Obsidian Sync's 5 MB per-file limit.
- Add settings search definitions for the plugin settings and use an Obsidian modal for reset confirmation.
- Restore accurate type checking for modern JavaScript APIs.

## Compatibility

- Requires Obsidian 1.13.0 or newer.
- Release assets: `main.js`, `manifest.json`, and `styles.css`.
