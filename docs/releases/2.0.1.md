# Quran Key 2.0.1

Patch release focused on tafsir cache integrity and discoverability.

## Changes

- Added a SHA-256 checksum to each persistent tafsir cache record. If cached commentary no longer matches its checksum, Quran Key fetches it again and updates the cache.
- Renamed cache files to identify the tafsir source, surah, and ayah; existing cache files are upgraded automatically.
- Kept cache migration within Obsidian's file APIs and sent replaced legacy files to the configured trash location.

## Compatibility

- Requires Obsidian 1.13.0 or newer.
- Release assets: `main.js`, `manifest.json`, and `styles.css`.
