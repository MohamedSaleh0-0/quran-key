# Quran Key 2.0.0

Major release for the Quran Key Obsidian plugin.

## Highlights

- Added reviewable conversion of unlinked Quran passages into ayah-note links, including manual resolution and rollback.
- Improved Quran extraction, snippet toggling, ambiguity handling, list formatting, and theme-aware Quran styling.
- Added tafsir packages, editable custom tafsir sources, configurable tafsir headings, and persistent vault caching.
- Added reflection-entry and ayah-note templates, quick category syntax, temporary categories, and clearer success feedback.
- Added migration for earlier color, tafsir, normalization, reflection, and note settings.
- Added the `ذى` → `ذي` normalization rule.

## Breaking and changed behavior

- The old global tafsir picker command was replaced by the contextual tafsir flow.
- Selection replacement with a generated reflection backlink remains deferred until editor replacement is reliable.
- Text-defined Quran ranges are not advertised as supported in this release; use a Quran citation or explicit text selection.
- Existing settings are migrated automatically where possible.

## Compatibility

- Requires Obsidian 1.13.0 or newer.
- Release assets: `main.js`, `manifest.json`, and `styles.css`.

## Network and privacy

Tafsir retrieval contacts `tafsir.app` or a user-configured endpoint only when the user explicitly runs a tafsir command. Quran search, extraction, normalization, and note workflows remain local. The plugin does not collect telemetry or vault data.
